# Spectrum Ledger
Original web adaptation inspired by the 1983 ZX Spectrum type-in game. Virtual chips only; no real-money play. Open index.html in a browser or publish the files to GitHub Pages. PWA installation and offline caching require HTTPS (or localhost). Progress and sound preference are saved locally. App icons included at 192, 512 and 1024 pixels.

Version 3: menu race artwork, numbered jockey sprites, animated gallop and responsive finish positioning. Existing local save key unchanged.
